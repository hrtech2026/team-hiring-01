## Как работаем

Задачи распределяем в чате, ревью проводим по мере готовности разделов. Синхронизируемся по необходимости перед сдачей этапа. Разделение по разделам — в соответствии с ролями. Изменения вносим совместно: сначала обсуждаем в чате, потом оформляем Pull Request.
