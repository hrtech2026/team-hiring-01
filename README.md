## Как работаем

В чате  распределяем задачи, проводим ревью, синхронизируемся по мере необходимости выполнения очередного шага, разделение по разделам осуществляем в соответствии с ролями, совместно вносим изменения в предварительно подготовленные материалы.


## Сдача

```text
1. Все документы в ветке main
2. Проверка validate-docs.yml зелёная
3. data/meta.yml актуален: состав, роли, этап
4. Карточка на доске переведена в нужную колонку
5. В комментарии к Pull Request есть тег: "Сдаю этап N"
```
